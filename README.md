# 강의안 커버 이미지 생성기 (GenerateCoverImage)

웹 브라우저에서 강의·워크숍·컨퍼런스용 커버 이미지를 생성하는 단일 페이지 도구입니다.

이 프로젝트는 OpenAI Codex를 사용하여 분석·설계·구현·검증했습니다.

## 주요 기능

- 브랜드, 산업군, 분위기, 청중, 스타일, 주제, 배경, 색상 입력
- 강의 커버 전용 기획 옵션
  - 커버 사용 목적
  - 핵심 시각 은유
  - 인물·대상 처리
  - 조명 연출
  - 카메라·시점
  - 재질·표면감
- 좌측 옵션 선택에 따른 영문 기본 프롬프트 실시간 생성
- 최종 프롬프트 직접 수정 및 클립보드 복사
- Gemini 텍스트 모델을 활용한 프롬프트 자동 구체화
- Gemini 이미지 모델을 활용한 커버 이미지 생성
- 이미지 다운로드, 클립보드 복사, 동일 설정 재생성
- 화면 비율 및 이미지 해상도 선택
- API Key 기준 사용 가능한 Gemini 모델 자동 조회

## 파일 구조

- `index.html`: HTML, CSS, JavaScript가 포함된 메인 웹 페이지
- `README.md`: 프로젝트 설명 및 사용 방법

## 사용 방법

별도 설치나 빌드 과정 없이 정적 HTML 파일로 실행할 수 있습니다.

1. `index.html`을 Chrome, Edge 등 최신 브라우저에서 엽니다.
2. 왼쪽 `API 설정` 영역에 Google AI Studio API Key를 입력합니다.
3. 필요하면 `모델 새로고침`을 눌러 현재 API Key에서 사용할 수 있는 Gemini 모델을 조회합니다.
4. 강의 목적, 핵심 시각 은유, 스타일, 주제, 색상, 여백 등을 선택합니다.
5. 생성된 기본 프롬프트를 확인하고 필요하면 추가 설명을 입력합니다.
6. `AI로 프롬프트 구체화하기`를 눌러 Gemini 텍스트 모델로 프롬프트를 확장하거나, 최종 프롬프트를 직접 수정합니다.
7. `이미지 생성하기`를 눌러 결과 이미지를 생성합니다.

## Gemini API 모델 조회

API Key가 입력되면 다음 API를 호출하여 현재 사용 가능한 모델을 확인합니다.

```text
GET https://generativelanguage.googleapis.com/v1beta/models?pageSize=1000
```

`generateContent`를 지원하는 Gemini 모델만 후보로 사용하며, 모델명에 `image`가 포함된 모델은 이미지 생성 모델 목록으로 분리합니다. API Key가 없거나 모델 조회에 실패한 경우에는 페이지에 포함된 기본 모델을 사용할 수 있습니다.

이미지 생성 요청에는 선택한 화면 비율과 해상도가 함께 전달됩니다.

- 화면 비율: 16:9, 4:3, 1:1, 9:16, 3:4
- 해상도: 1K, 2K, 4K

- Vanilla JavaScript
- Google Gemini API
- OpenAI Codex: 코드 분석, 기능 설계, 구현 및 검증

## 참고 사항

- 개인 또는 내부 사용을 전제로 한 브라우저 실행형 도구입니다.
- API Key는 브라우저에서 직접 Google Gemini API 호출에 사용됩니다.
- 이미지 모델이 선택한 해상도나 화면 비율을 지원하지 않는 경우 API 오류가 발생할 수 있습니다.
- 클립보드 복사 기능은 브라우저 보안 정책에 따라 HTTPS 또는 localhost 환경에서 동작하지 않을 수 있습니다.
